SNES RA v2.0 - TESTE DOS 99 QUEIJOS

1. Compile o firmware com build_windows_pico_sdk.ps1 ou pelo workflow do GitHub.
2. Grave build\snes_rp2350b_capture.uf2 no RP2350B. ESTE TESTE EXIGE REFLASH.
3. Mantenha a mesma fiacao: GP39=/WRAMSEL e GP40=A10.
4. Coloque somente Tom and Jerry (USA).sfc/.smc nesta pasta.
5. Inicie INICIAR_RA_v2.0_DIAGNOSTICO.bat.
6. Abra o RA2Snes em SOFTCORE e jogue normalmente.

O terminal deve mostrar:
[CHEESE-RA] ... +01558 e/ou +0155C   -> prova que o RA esta pedindo o contador
[CHEESE] +01558=.. / +0155C=..       -> valor fisico espelhado
[WRAMSEL] ... read_repair=...         -> quantas leituras corrigiram escrita perdida

Ao chegar em 99, procure 63 hexadecimal:
[CHEESE] +01558=63 ...
ou
[CHEESE] +0155C=63 ...

Interpretacao:
- Se aparecer 63 e [CHEESE-RA] para o mesmo byte, o caminho SNES -> firmware -> bridge esta correto; qualquer falha restante fica no trigger/estado do RA.
- Se o jogo mostra 99 mas o probe nao chega a 63, o problema ainda esta na captura fisica do WRAM.
- Se chega a 63 mas nunca aparece [CHEESE-RA], o RA nao esta consultando esses offsets para a conquista ativa, entao precisamos extrair o trigger real carregado pelo cliente.

Nao execute QUsb2Snes ao mesmo tempo; a porta WebSocket 23074 precisa ficar livre.
