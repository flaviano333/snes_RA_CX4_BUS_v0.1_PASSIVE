TESTE v0.4.3

1. Build GitHub artifact CX4_v0.4.3_GENERIC_SEM_ROM.uf2.
2. Inject your Mega Man X2 ROM with INJETAR_ROM_NO_UF2.bat.
3. Flash the _COM_ROM UF2.
4. Run CX4SELF (expect 21704 instructions / 1024 rdrom).
5. CX4RESET, CX4ARM, reset SNES.
6. Enter intro/game and run CX4STAT.

Key fields:
- armed=1, driven>0
- ioq_drop=0
- hle_badparts should be low and ideally stop growing rapidly
- hle_zptr/hle_oor should fall sharply if speculative corruption was the cause
- fwd_put>0 and fwd_hit may be >0
- sio_block should grow: these are speculative samples intentionally prevented from mutating canonical state

Observe whether Mega Man/enemy sprites become coherent.
