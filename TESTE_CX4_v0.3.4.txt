TESTE RAPIDO v0.3.4

1. Build generic UF2 in GitHub Actions.
2. Inject your own Mega Man X2 ROM with INJETAR_ROM_NO_UF2.bat.
3. Flash *_COM_ROM.uf2.
4. Start with CX4STAT. Verify core=1 rom_slot=1 firmware=1.
5. CX4RESET
6. CX4ARM
7. Reset SNES and run the built-in CX4 test.
8. If it freezes, run CX4STAT then CX4TRACE.

Important fields:
- ioq_drop must be 0.
- runs/insns/rdrom should increase after $7F4F starts.
- A much smaller instruction count than v0.3.3 is expected if the runaway/race was fixed.
