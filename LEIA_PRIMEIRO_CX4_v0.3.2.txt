SNES RP2350B - CX4 BUS v0.3.2 LLE ROM-SLOT TURBO
=================================================

POR QUE EXISTE ESTA VERSAO
--------------------------
A v0.3 exigia cx4_game_rom.bin durante o CMake. Isso funciona num build local,
mas NAO funciona no GitHub Actions: o runner nao possui a ROM particular do
usuario. Alem disso, o workflow antigo nem baixava o core LLE antes de chamar
CMake, causando o erro "CX4 LLE ausente".

A v0.3.2 separa as duas coisas:
  1. GitHub Actions compila um UF2 GENERICO, sem ROM comercial.
  2. No seu PC, um script injeta a SUA ROM no UF2 pronto.

A ROM nunca precisa ser enviada ao GitHub e voce nao precisa ter Pico SDK local
se usar o UF2 generico gerado pelo Actions.

GITHUB ACTIONS
--------------
O workflow agora baixa/adapta o core CX4 automaticamente e gera:
  CX4_v0.3.2_GENERIC_SEM_ROM.uf2

Esse UF2 compila normalmente, mas CX4STAT mostrara rom_slot=0/core=0 se voce o
gravar sem antes injetar a ROM.

INJETAR A ROM LOCALMENTE
------------------------
Depois de baixar o artifact do GitHub Actions:

  .\INJETAR_ROM_NO_UF2.ps1 `
      -Uf2Path ".\CX4_v0.3.2_GENERIC_SEM_ROM.uf2" `
      -RomPath "C:\ROMs\Mega Man X2 (USA).sfc"

Ou:

  INJETAR_ROM_NO_UF2.bat CX4_v0.3.2_GENERIC_SEM_ROM.uf2 "C:\ROMs\Mega Man X2 (USA).sfc"

O script gera:
  CX4_v0.3.2_GENERIC_SEM_ROM_COM_ROM.uf2

E ESSE e o arquivo que deve ser gravado no RP2350B.

COMO FUNCIONA
-------------
A SpotPear RP2350B Mini A possui 16 MB de flash. O firmware ocupa a area baixa
e a v0.3.2 reserva um slot a partir de 4 MB para a ROM do jogo. O script apenas
adiciona blocos UF2 para esse slot; nao altera nem publica o arquivo .sfc/.smc.

No boot o firmware procura o cabecalho "CX4R" nesse slot e, se encontrar,
passa a ROM diretamente ao core HG51B/CX4 por XIP.

TESTE
-----
1. Grave o UF2 COM_ROM.
2. Rode Mega Man X2 no Flash Master.
3. Envie CX4STAT. Antes de armar, procure:
     rom_slot=1 rom_bytes=... core=1 firmware=1
4. Envie:
     CX4RESET
     CX4ARM
5. Resete o SNES e rode o autoteste.
6. Envie CX4STAT novamente.

Se aparecer rom_slot=0, a ROM nao foi injetada no UF2 que voce gravou.
